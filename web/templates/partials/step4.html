🔍 TP Search Depth
How many Tensor Parallelism combinations to test for prefill/decode splits. Higher values test more combinations but take longer.
Example with TP options [1, 2, 4, 8]:
If calibration finds prefill is fastest at TP=8 and decode is most efficient at TP=1:
Depth 1 → tests only (PTP=8, DTP=1) → 3 splits
Depth 2 → adds 2nd-best TPs, cross-product → 4 pairs → ~20 splits
Depth 4 → all TP combinations → up to 10 pairs → ~40+ splits
More splits = longer total runtime. Depth 2 is recommended for most workloads.
