What's your priority?

Pick what matters most to you. In-S8 will automatically test different server configurations to find the best one for your needs.

🎯 How it works

Throughput Priority: Tests different server setups to find the one that handles the most requests at once -- like finding the highway lane configuration that moves the most cars per hour.

Response Time Priority: Tests different server setups to find the one that starts replying fastest -- like finding the checkout lane that begins scanning your items soonest.

Balanced: Tests all available server setups to find one that gives a good balance of fast response times and high request volume.

Throughput Priority

Finds the setup that handles the most requests and generates the most text per second. Best when you need to serve many users at once.

Benchmarks: Standard setup vs Expert Parallelism (EP)

Response Time Priority

Finds the setup where users see the first word of the AI's reply as fast as possible. Best for chatbots and interactive apps where feeling "instant" matters.

Benchmarks: Standard setup vs Prefill/Decode split (PD)

Balanced Performance

Tests all server configurations and picks the best overall tradeoff between fast replies and high request volume. Ideal when you want solid performance across the board.

Benchmarks: All configurations (Standard, EP, and PD)
