What's your priority?

Pick what matters most to you. ServeIt Studio will automatically test different server configurations to find the best one for your needs.

🎯 How it works

Throughput Priority: Tests different server setups to find the one that handles the most requests at once -- like finding the highway lane configuration that moves the most cars per hour.

Response Time Priority: Tests different server setups to find the one that starts replying fastest -- like finding the checkout lane that begins scanning your items soonest.

Full Coverage: Tests all available architectures including multi-node TEP (Tensor + Expert Parallelism) to find the best overall winner.

Single Architecture: Already know which architecture you want? Pick Aggregated Only, PD Only, or EP Only to skip the comparison and go straight to optimizing that architecture.

Throughput Priority

Finds the setup that handles the most requests per second for your specific model and workload. Tests Aggregated and EP (including multi-node TEP when multiple nodes are available), picks whichever wins.

Compares: Aggregated vs EP/TEP — best config from each is compared

Response Time Priority

Finds the fastest first-reply time for your specific model and workload. Aggregated can beat PD in some cases, so we test both and pick the winner.

Compares: Aggregated vs Prefill/Decode (PD) — best config from each is compared

Full Coverage

Tests every possible architecture for your model and workload — Aggregated, PD, EP/TEP (single and multi-node), and PD-EP (disaggregated with Expert Parallelism). Picks the best overall winner.

Compares: Aggregated vs PD vs EP/TEP vs PD-EP — best config from each is compared
