Automatic Storage Setup
Storage setup and model download will begin automatically when you start the optimization in the next step. The system will:
  • Create PVC if it doesn't exist
  • Download model from HuggingFace (if not using existing PVC)
  • Validate model architecture and configuration
📦
Using Existing PVC
When you generate the test plan, Inftune Studio will:
  • Read model config.json from the PVC
  • Determine architecture (layers, KV heads, etc.)
  • Calculate accurate VRAM requirements
  • Skip model download (assumes model is already present)
